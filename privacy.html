Privacy Policy

Effective October 26, 2026

Beavis Assistant is a private application used by a single household. It is not available to the public.

What it accesses

With the account owner's explicit consent, the app reads, labels, and sends Gmail messages and reads and creates Google Calendar events for the owner's own account, solely to provide personal assistant features to that owner.

What it does not do

  • It does not sell, rent, or share Google user data with anyone.
  • It does not use Google user data for advertising.
  • It does not use Google user data to train general-purpose AI or machine-learning models.

Storage and security

Data is processed on the owner's own computers. Access tokens are stored locally with restricted permissions and can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
